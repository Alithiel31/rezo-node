## Backend (`api/`)

```bash
cd api
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt
cp .env.example .env
# edit .env — see docs/environnement.en.md
python manage.py migrate
python manage.py runserver
```

`DB_HOST` points by default to Caesura's shared PostgreSQL instance — there is no local Postgres
container in this repo yet.

## Frontend (`web/`)

```bash
cd web
npm install
npm run dev   # http://localhost:3000
```

Default `create-next-app` scaffold, no game-specific page yet.

## Tests and CI

No test suite or CI pipeline exists yet — only the empty `tests.py` stubs generated by Django are
present in each app.
