WeatherQC (`docs/accessibilite.md` sur ce repo) : audit automatisé + vérifications manuelles
(contraste, navigation clavier, lecteurs d'écran), en particulier pour un rendu visuel abstrait
type Mini Metro où l'information ne doit pas reposer uniquement sur la couleur.
