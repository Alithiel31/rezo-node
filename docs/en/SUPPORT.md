# Getting help

🇫🇷 [Version française](../../SUPPORT.md)

Rezo Node is a personal project, maintained by a single person in their spare time: there is no
commercial support and no guaranteed response time.

## Before asking for help

1. Check [TROUBLESHOOTING.en.md](../../TROUBLESHOOTING.en.md).
2. Search [existing issues](https://github.com/Alithiel31/rezo-node/issues), open and closed.

## Reporting a bug or requesting a feature

Open an [issue](https://github.com/Alithiel31/rezo-node/issues/new).

## Contributing

See [docs/en/CONTRIBUTING.md](./CONTRIBUTING.md).

## Reporting a security vulnerability

**Do not** use this channel for a security flaw — see [docs/en/SECURITY.md](./SECURITY.md).
